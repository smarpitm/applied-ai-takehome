Secret Management and Envelope Encryption

KMS Envelope Encryption

Tenant document payloads stored in object storage are encrypted using AES-256-GCM data encryption keys (DEKs). Each DEK is wrapped by an AWS KMS customer-managed key rotated every 365 days, and plaintext DEKs never touch persistent disk. Decryption happens solely in volatile worker memory during chunk extraction and query synthesis.

Secret Scanning and Pre-Commit Gates

CI pipelines reject pull requests containing high-entropy API tokens or .env files. Local developers load credentials exclusively via .env files excluded from git and read through pydantic-settings SecretStr fields, ensuring API keys never serialize into structured JSON telemetry logs or exception stack traces.

Key Rotation Runbook

Compromised API credentials must be revoked at the provider console within 15 minutes and rotated across staging and production secret vaults using zero-downtime dual-secret overlap windows.
