Cursor Pagination and Tenant Rate Limits

Opaque Cursor Pagination

List endpoints return opaque base64url next_cursor tokens with a default page size of 50 items and a hard upper limit of 200 items per request. Offset-based pagination is disabled above 10,000 rows to avoid linear table scan degradation. Cursors expire after 60 minutes and bind to the caller's original filter predicate hash.

Token Bucket Quotas

Free-tier tenants receive 30 queries per minute (burst 10) and 50 MB of vector storage. Standard-tier tenants scale to 600 queries per minute with bursting up to 100 concurrent requests via token-bucket limiters. Response headers X-RateLimit-Remaining and X-RateLimit-Reset expose live bucket headroom on every API call.

Payload Compression

API responses above 1 KB automatically apply zstd or gzip HTTP content encoding when advertised by Accept-Encoding headers.
