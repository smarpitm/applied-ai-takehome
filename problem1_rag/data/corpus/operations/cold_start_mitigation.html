Cold-Start Tail Latency Mitigation

NVMe Page Cache Warming

To bound cold p95 retrieval latency on serverless workers, NimbusStack pins IVF coarse centroid tables (under 4 MB for 10M vectors) inside an ephemeral NVMe read-through cache of 8 GB per worker node. Subsequent queries hitting warmed PQ codebooks drop from ~190 ms cold S3 fetch down to ~18 ms warm local read.

Batch Compaction Schedule

Incremental ingestion writes small fragment files that degrade scan throughput if left uncompacted. A nightly compaction job merges fragments exceeding 50 deletes or more than 16 delta files into contiguous 256 MB Lance segments, keeping read amplification bounded across months of incremental document updates.

Connection Pool Sizing

Object-store HTTP clients maintain up to 64 keep-alive connections per worker so parallel IVF partition range-reads avoid repeated TLS handshakes.
